# Asset register

The SVGs in docs/media are original repository artwork for Kombelo documentation. They have no external dependencies. Runtime and store art are separate exports. Enforce this register for all imported binaries before distribution.

| Role | Chosen source | Intake state |
|---|---|---|
| README mark and documentation pictograms | docs/media, original project artwork | Checked in |
| Runtime interface controls | [Lucide](https://lucide.dev/license), pinned upstream release and applicable notices | Select and vendor at UI slice |
| UI click and clear textures | [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds), verify archive and exact per-file rights | Review and choose at UI slice |
| Record and combo motif | Original D5–F#5–A5 chime, synthesize or record, retain source and exact export | Produce at UI slice |
| Supplemental fonts | Noto family, verify script, upstream provenance and OFL file | Vendor when coverage requires |

For each selected export store logical event, repository path, upstream URL and revision, creator, license SPDX ID, actual notice path, original checksum, final checksum, changes and reviewer. Keep source and optimized output distinct. Compare candidates on physical Android speakers. Collect WAV masters and only bundle supported optimized formats once playback latency and focus are verified. No copied samples or unverified archives.
