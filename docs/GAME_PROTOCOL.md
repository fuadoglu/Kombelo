# Deterministic game protocol · v1

Read [catalog and constants](../contracts/game-v1.json) and [replay vectors](../contracts/game-v1-vectors.json). Rows and columns are zero-based. Board is an array of eight row strings. '.' is empty; '#' in a vector means occupied regardless of color. Runtime cells carry a palette index 0–4. Occupancy alone affects gameplay.

Classic generation: unsigned 32-bit xorshift, replace seed zero with the configured nonzero value; apply xor with left 13, unsigned right 17, left 5 in order, mask to 32 bits after each xor. Use unsigned integer semantics across VM and web (Dart unsigned shifts and explicit normalization, or equivalent). Draw three slots in order. Each slot consumes exactly three RNG outputs: first modulo sum of catalog weights selects the shape by ascending catalog array order; second modulo unique rotations count selects its orientation; third modulo palette size selects color. Rotate masks clockwise from listed orientation, trim empty border rows/columns and deduplicate by first occurrence. No reflections except explicitly listed masks. Persist RNG state after drawn values. Inputs, time, ads and score never alter generation.

Ranked boards store the immutable starting grid and an explicit sequence of complete trays of oriented pieces/colors. Include enough trays for the move cap and terminal refill. Compute SHA-256 over UTF-8 of RFC 8785 canonical JSON payload, excluding the digest field itself. Board envelope also has ID, version, UTC open/close and move limit. Server keeps prior rules for active attempts and supported old saves.

Move ordering: validate active state, slot, bounds and occupancy; apply cells; find full rows and columns from one snapshot; clear their union; update chain and score; consume slot; refill if all slots consumed; evaluate terminal. Cap is checked after the committed move and has precedence over empty legal-placement search. Effect state is derived, never persisted as gameplay state. Evaluate valid preview and commit with the same pure function. Every illegal or canceled move preserves board, score, tray and RNG.

Score: placed cells + 10n + 5n(n−1) + clearing-only 3×min(9, chain−1), where n counts cleared rows plus columns and chain is post-move consecutive clears. Nonclear resets chain. Fixture weights and points change only by new rules version once public.

Undo eligibility simulates alternate legal placements in the immutable pre-move state, excluding the exact original slot/row/column. An alternate must reach a nonterminal state; the same refill/RNG applies. Freeze result and pre-move snapshot before advertising. Cancel/error spends no entitlement. Grant and restore transactionally at most once per run, using an entitlement keyed by ad request. Accept valid earned callback even if dismissal came first; route updates only if the run still owns its result state. Define the in-flight UI so starting a new round cannot silently discard an already earned reward. Keep a recoverable pending grant in durable storage once confirmed and never infer a grant from dismissal. Finalize personal best when the player exits the result or starts another run, never from an abandoned undone score.
