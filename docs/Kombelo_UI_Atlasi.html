Klassik lövhəni oyna və ya ekran xəritəsindən Liqa, profil və ayarları aç.

Rəng sistemi

Dizayn qərarları

  • Xal, lövhə, fiqurlar: ekranın oxunuş sırası.
  • Sarı əsas düyməni və rekordu, firuzəyi etibarlı hədəfi vurğulayır.
  • Boş xana, dolu xana və önizləmə forma və konturla seçilir.
Ekran xəritəsi və prototip sərhədləri

İlk açılış → ilk gediş → Klassik → pauza və ya nəticə. Nəticə → ikinci şans və ya yeni oyun. Liqa → gündəlik cəhd və ya nəticələr → dostlar, ölkə və dünya. Profil → ad və ölkə, dostlar, hesab. Ayarlar → dil, bildiriş, məxfilik və hüquqi səhifələr. Liqa rəqəmləri, reklam, hesab və hüquqi mətnlər nümunədir. Prototip brauzerdə lokal işləyir və heç bir hesab, reklam və ya məlumat göndərişi yaratmır.
