# Service behavior and acceptance

Use authenticated subject for identity; reject player IDs supplied by clients as authority. The provider performs optional email recovery and upgrades anonymous credentials without changing subject, or uses a transactional ownership migration if the verified provider requires it. A recovery code or a public code is not a credential. Authorize deletion against a recent session, revoke provider access, expire device tokens and reconcile leaderboard views. Prefer database-backed jobs for external retries.

UTC daily and Monday UTC weekly boundaries. Accept submits based on server receipt timestamp captured before processing, subject to authorization and verification. Take a per-player/board transaction lock when starting, return the existing attempt for the same idempotency key, and reserve the lowest unused slot if open. Replays must start from the bound board state and finish exactly at terminal; extra moves fail. Return the prior confirmed result for identical final replay retries, even after close; different replay yields 409. Use 410 for expired unopened/unfinished attempts, 429 for throttling and 422 for illegal moves. Void board scores are excluded in all views. For daily and weekly ranking, filter eligibility and blocks first, aggregate best scores, compute RANK by score alone, then order equal rows by stable public code for pagination. Bind cursors to query and snapshot version, restart pagination if version is stale. Freeze the first country snapshot per player and week. No country when unset.

Friend invite requires recipient acceptance. Blocks remove pending and accepted relationships, suppress peer notifications and prevent new invites. Limit nickname mutations and invite/report traffic. Automated nickname filters consider grapheme length and bidi controls; allow natural scripts and manual correction. Operator review can dismiss or reset a name and records reason without collecting unrelated message content.

Test cases: simultaneous third attempt is refused; identical replay after cutoff returns same score; conflicting replay returns 409; stale cursor restarts; a score tie crossing a page produces equal rank; a void board removes its contribution; blocked mutual user cannot send a new invite; account deletion clears profile, device subscriptions and cached rows. Public daily sequence permits shared solutions. Server validation proves legal play, not independent authorship.
